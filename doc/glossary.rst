********
Glossary
********

.. glossary::

   Assembly
      Human-readable, mnemonic representation of processor instructions.

   Control hazard
      A pipeline condition caused by a change in control flow, such as a
      branch or jump.

   Data hazard
      A pipeline condition in which an instruction needs a result that a
      preceding instruction has not yet made available.

   Forwarding
      Passing a result directly between pipeline stages to resolve eligible
      data dependencies before write-back.

   GHDL
      An open-source VHDL analyzer, compiler, and simulator.

   GTKWave
      A waveform viewer used to inspect signal traces from simulations.

   RISC-V
      An open instruction set architecture (ISA).

   RV32I
      The 32-bit base integer RISC-V instruction set.

   RV32M
      The RISC-V standard extension for integer multiplication and division.

   VHDL
      A hardware description language used to describe and simulate digital
      logic.
